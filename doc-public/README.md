# SpyDER public documentation

This directory contains documentation intended for publication and inclusion in
source distributions. Public guides will be added here as they are prepared.

- [Project overview and setup](../README.md)
- [Contributing](../CONTRIBUTING.md)

Engineering notes and drafts belong in the local `docs/` directory, which is ignored
by Git and excluded from source distributions. Keep public documentation links
within this directory or point them to the public project entry points above.
