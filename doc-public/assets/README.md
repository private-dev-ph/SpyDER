# Showcase media and footage credits

These assets are screen recordings of SpyDER running its bundled demo cameras.
Control Room and Vision Lab were recorded from an isolated installed Python runtime;
the workflow clip shows the enabled bundled porch Approach workflow in the static browser demo.
The videos and animations are silent, six-second extracts of the real UI. Screen capture,
resizing, frame-rate reduction and compression were applied. No footage or detection results
were generated. Original source watermarks and camera timestamps remain inside the feeds.

## Formats

- `*.webp`: looping previews for the portfolio’s image-only visual sections and README.
- `*.mp4`: H.264/yuv420p with fast-start metadata for video playback and presentations.
- `*.png`: still posters from the same captures.
- [showcase-media.json](showcase-media.json): runtime context, source IDs and file inventory.
