# Portfolio and presentation assets

[Documentation home](README.md)

## Project metadata

The root [portfolio-showcase.json](../portfolio-showcase.json) describes SpyDER's
problem, purpose, features, technology, implementation decisions, and results for the
companion portfolio. Asset paths in that file are relative to the repository root.
Keep metadata consistent with implemented behavior and the current hosting status.
A local export alone does not establish that a live demonstration is deployed.

Screenshots illustrate interface behavior, not production surveillance or model
accuracy. Keep real camera addresses, faces, recordings, identities, and uploaded
weights out of presentation assets. Include meaningful alternative text and captions
when embedding screenshots. The application uses the shared SVG icon sprite for
interface controls and PNG for these presentation images.

[documentation index](README.md) rather than duplicating entire guides in portfolio text.
